## 本次范围

新增所有人可访问的 `/help` 页面，在登录页和通用顶部栏提供所有人可见的「帮助」导航，兼容手机与 Pad 网页。此授权只限本帮助页开发和测试，不部署、不合并、不恢复历史任务。

项目介绍严格展示「手机端优先的轻量库存管理系统」。功能列表严格展示以下八项，不增加其他功能或 MCP 工具数量：

1. 品类管理
2. 库存品管理
3. 出库及回滚
4. 盘点差异记录
5. 库存搜索和低库存提示
6. 补货申请及状态流转
7. 配方驱动的生产录入
8. 面向 AI 的 MCP 数据访问服务

这份清单是已确认采用的项目文档表述，不表示本任务逐项运行验证了所有功能。

页面底部设置「意见反馈」区域和「反馈」按钮。登录后使用既有 `data-feedback-open` 打开 `#feedback-modal`；无脚本时走原 `feedback.new_feedback` 页面。匿名点击先经原登录和选仓流程，保留同源 `next`、原反馈 API、角色权限与 CSRF，不开放匿名提交，不扩张库存或管理数据访问。
